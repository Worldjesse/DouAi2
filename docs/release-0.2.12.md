## 本次正式发布的累计更新

本版汇总 0.2.7 之后的本地变更，历史候选的独立产物与当时验收范围继续保留：

- **语音格式与设置**：MiniMax 新增实验 AAC、Ogg/Opus、μ-law WAV、URL/Hex 返回和最多四种音色混合，整理基本与高级设置。实验 AAC 直接请求服务接口，可能被拒绝；评论语音使用生成原文件，保留既有时长、重试与回退策略。见 [0.2.8](release-0.2.8.md)。
- **40809900 适配**：迁移 40.8 新构建的 75 条规则、18 个聊天/相册映射和相关安全任务分支，按真实 Manifest 内部号选择配置；后续补齐下载工厂与 LivePhoto 映射，保留 40.6。见 [0.2.9](release-0.2.9.md)、[0.2.10](release-0.2.10.md)。
- **评论语音与反射**：生成评论语音使用非空默认波形，覆盖已定位的 KMP 气泡显示门槛；保留原音频内容，并修复 R8 改写宿主 Kotlin 反射类名的独立问题。用户已确认 0.2.10 新评论的显示与播放恢复，此反馈不代替本版新增功能的手机验收。见 [0.2.10](release-0.2.10.md)。
- **全局长按转语音**：在“评论相关”开启默认关闭的 `#长按发送转语音（全局）`，输入 `#内容` 后长按原生发送按钮，覆盖私信、群聊、评论及评论回复。失败保留草稿并提示，原单击转语音设置独立。见 [0.2.11](release-0.2.11.md)。
- **进度与调试**：聊天回复从处理、生成与合成阶段显示进度；浮窗保留约 18 dp 主体与 32×32 dp 触摸区，以冷蓝对话和暖琥珀铅笔图标区分回复与评论，支持闲置降亮与微移。关于页提供分类搜索、逐条查看、JSON 格式化、复制和完整日志导出。见 [0.2.11](release-0.2.11.md)与[调试说明](debug-logging.md)。

详细日志默认关闭；开启后会保留评论、聊天和音频对象快照，密钥、令牌与 URL 查询先脱敏，正文、ASR 和对象标识仍可能保留。关闭只影响之后的记录，清空才删除已有日志；导出包含完整保留日志，不受页面筛选影响。

## 问题与修复

用户日志中三次点击“关于 → 调试与日志”的崩溃完全一致。使用 0.2.11 对应 mapping 还原到 Miuix BasicComponent 的 Component.kt:220。调试页类别筛选框位于横向加权布局，Android 为获取基线先按无界宽度测量控件；Miuix 0.9.4 的比例计算发生整数溢出，形成负 maxWidth，触发主线程异常。

在调试页横排行的局部 helper 关闭不需要的基线对齐，使控件按分配后的有限宽度测量。保留原布局、筛选、搜索、复制、导出与日志通道。生产变更只有该修复和版本更新，原小浮窗、语音发送与双版本适配的源码保持 0.2.11 状态。

原有日志页测试只覆盖 miuix=false，漏掉了宿主真实 Compose 控件路径。新增真实 Miuix / HostComposeContext / native graphics 布局回归：修复前 **2 项全部失败**，异常及关键帧与手机一致；相同测试修复后 **2 项全部通过**。覆盖完整对话框及 296/260/220 dp 的整页测量，不以“控件未显示”绕过问题。
