# 本地人物侧写

人物侧写只描述搭载模块的使用者在这份本地记录中的内容接触、节律、工具使用和变化，不建立多用户档案。入口是抖音设置 → DouAi → 扩展功能 → 本地数据分析。

日常采集与指标计算都在本机完成。保持默认关闭；已有开启状态随升级保留。主动点击“请求 AI 分析”时，才发送统计摘要、前期及 7/30 天对照、融合指标、关联摘要和填写的使用目的。

报告与模块其他页面共用弹窗和控件样式，内容区块可展开、收起，默认简洁展示。默认配置备份不包含分析数据；备份页可主动勾选包含统计、关联、自述及反馈。导入时需另选恢复分析，采用替换方式，保持本机采集开关不变，见[本地数据分析](local-analytics.md)。

## 侧写与图表

| 展示 | 依据 | 解释边界 |
| --- | --- | --- |
| 这段时间的你 | 本地计算的组合观察、证据数字、样本说明 | 不是心理人格测评，可展开查看依据 |
| 日历热力 | 按本地日期的浏览记录 | 空白是无记录，不证明未使用 |
| 内容构成变化 | 每日类型计数汇为短周期堆叠 | 图集、实况图集、直播卡片互相区分 |
| 话题版图 | 全量话题计数，展示前八与其他 | 分母为话题出现总次数，一条作品可多话题 |
| 作者集中曲线 | 全量已识别作者分布，展示头部与尾部 | 未识别作者不算一个真实作者；显示识别覆盖 |
| 星期 × 小时热力 | 真实日期与小时计数 | 展示记录发生时段，不等于作息或睡眠 |
| 和自己对照 | 等长前期、7 天和 30 天窗口 | 今天未结束，前期不足时不计算增长率 |
| 话题迁移 | 同名话题的前后排名、次数 | 未进入摘要不等于没有出现，更不等于没有兴趣 |
| 从接触到行动 | 显式关联到同一可见片段的小时/话题、类型/动作 | 不用独立排行拼造关联，不推断因果 |

作者和话题的均匀度由完整分布计算，不限于旧页面的 Top 10。跨日重逢以作品哈希在不同日期出现为依据，不称为主动回看率。浏览日数仅包括有浏览记录的日期；功能活跃日可以与浏览日不同。

本地组合观察把分布、节律、重逢、工具来源和跨期变化组织成可解释的维度。相同数据的多个派生指标不是独立证据。夜间记录多、某话题多和下载多，不能据此断言“夜间喜欢保存该话题”。

跨版本对照还会受到统计口径变化影响：本版增加了下载请求、完成阶段及关联记录，功能事件变多不一定表示使用频率增长。对照展示的是保留记录，不能直接推断行为原因或人格变化。

## 从升级后增加的关联

原有按天统计保持兼容，schema v2 增量增加可见片段、关联话题、动作阶段和采集边界，旧记录不会回填停留或关联。

- 可见性约每 750 毫秒检查一次，依据前台、窗口焦点、当前作品及可见范围。采样间隔超过 1500 毫秒的缺口不计入。
- 失焦、进入后台或作品变化会结束片段；同一作品恢复可见时可开启新片段，浏览去重不重复增加。
- 可见停留约每 3 秒保存检查点，结束时保存余量。进程终止可能丢失尚未落盘的尾部，排队也会影响落盘时机。单片段累计上限 30 分钟。
- 可见不代表注视、完整播放或喜爱；不能保证识别所有同窗口遮挡。
- 自动翻页使用有时限的一次性标记；无可靠来源时保留“未知”，不把未知自动归为手动。
- 手动复制、保存入口、快捷评论、倍速，以及自动点赞/关注/翻页按已知来源记录。入口、请求、受理与成功各保留语义。
- 延迟动作携带当时捕获的作品与片段令牌。令牌过期时仍可记独立功能事件，但不借用后来作品建立关联。
- “下载任务完成”只在下载管理器确认任务 completed 时计数；解析成功、取消和失败不算保存成功。一次任务可能含多个文件，一次操作也可能建立多个任务，因此不能直接用任务计数计算操作转化率。完成事件不关联后来刷到的作品。

按天汇总仍最多保留 365 天。关联明细最多保留 30 天，并限制为 20,000 个片段、30,000 条动作。队列满时拒绝新增统计并记录缺口数量。报告明示这些覆盖限制。

## 主动请求 AI 侧写

AI 接收确定的统计与本地证据，返回侧写标题、综合描述、反差与变化、一个自我观察问题，以及原有七组图表解读。每项有长度和结构约束；缺失字段或格式不完整视为失败，可重试。

数字和关联由本地计算，模型负责组织语言；保留已配置的全局提示词。不发送作品原始 ID、媒体文件、逐条精确浏览时间、私聊或评论正文，不混入其他对话历史。关联摘要和长历史有数量与体积限制，必要时省略重复对照并明确标记。

“我的使用目的”是可选自述，最多 240 字；模型必须将自述与观察分开解释。“最近一次侧写反馈”仅保存在本机，不会自动训练模型、修改统计或被当作性格事实。保存反馈保留当前解读和分享入口；修改使用目的、刷新或切换范围会清除旧解读，需重新主动请求。

分享通过系统选择器发送侧写与分图解读、范围和分析时间，不附加数据库、接口密钥或原始事件。清空会删除统计、关联明细、自述和反馈，保留 AI 模型配置。

## 验证入口

`PortraitAnalyticsTest` 验证迁移、全量分布、比较窗口、未知数据和关联真实性；`LocalAnalyticsHookTest` 验证可见性、暂停与恢复；`DownloadTasksAnalyticsTest` 验证确认成功阶段；`AnalyticsAiAnalysisTest` 通过本机模拟接口验证请求与输出；`LocalAnalyticsDialogTest` 验证图表、反馈、分享及深浅色排版。

本地测试和静态宿主契约不等于真实设备采集验收。发布与构建结果见 [0.1.81 交付记录](release-0.1.81.md)。
