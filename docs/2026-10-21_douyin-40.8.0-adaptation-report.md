## Path 与验证边界

`P-1 / callflow`：真实 Manifest 身份 → 当前规则指纹 → 每DEX扫描 → 唯一候选 → 参数/字段/继承安装合同 → 功能Hook。版本及各自规则指纹更新会使旧扫描缓存失效；无需额外清除用户配置。

`P-2 / callflow`：安全回调创建带discriminator的共享任务 → 执行时读取开关 → 仅目标分支返回宿主 Kotlin Unit。关闭、非目标分支、安装不完整或合同异常时继续原流程。原 APK 合同验证任务身份和调用顺序，行为回归验证模块边界；均不说明隐藏内容可播放。

本轮先复现旧规则与导航失败，再迁移规则/控件/调用，最后运行统一 Gradle 与签名包验收。原 APK 静态合同、Robolectric合成界面、历史40.6 smali对照分别记录，不能互相替代。已有0.2.6平台模拟器结果不复用为本版的平台或手机验收。
