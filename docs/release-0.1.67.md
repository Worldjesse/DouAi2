# 0.1.67：下载分类、动态视频多选与 Miuix 弹窗

版本：`0.1.67 / 68`，本地交付，基于 0.1.66。官方下载手势先选择媒体类型，再选择保存操作，避免图片、动态视频和实况动作平铺在同一层。一个作品中的多个动态视频现在与图片一样支持当前项、多选和全部保存。

## 使用

“下载相关 → 下载方式”选择“官方下载”，触发“保存媒体”手势或手势快捷菜单中的同名入口：

| 层级 | 显示与操作 |
| --- | --- |
| 保存媒体 | 按当前内容显示“图片（N）”“动态视频（M）”“实况（K）”，普通视频作品显示“视频”“音频” |
| 图片 | 多图支持保存当前图片、选择图片保存、保存全部图片 |
| 动态视频 | 多图支持保存当前动态视频、选择动态视频保存、保存全部动态视频；当前项属于静态图片时不会提供错误的当前动态保存动作 |
| 实况 | 多图支持保存当前实况、选择实况保存、保存全部实况 |
| 多选 | 仅列出所属类型，保留原图集序号；勾选后点击保存 |

只有一张图片时，对应分类只显示单项保存动作。分类页和多选页都有“返回”和“取消”；返回回到上一层，取消关闭本次选择。进入分类、勾选、返回和取消都不会创建下载任务。

同一张实况既能保存静态图片，也能保存动态视频或完整实况，因此它可以同时出现在三种保存类型中，数量不是互斥作品数。明确标记为实况但没有可读动态地址时，保留类型并在确认保存后说明缺少来源。

第三方下载保持选定方式的独占执行；本次分类流程针对官方下载。已有命名模板、去水印来源优先级和保存目录继续生效。

官方下载新增“默认行为”开关，默认关闭。开启后，“保存媒体”手势按旧默认方式直接保存视频或全部静态图片，不显示下载分类与选择弹窗；需要选择动态视频、实况或音频时关闭此开关。开关只在官方下载设置中显示，切到第三方时保留配置但不影响第三方路由。已有保存位置、命名和去水印选项继续生效，配置备份可携带此布尔值。

## UI 对齐

所有下载分类、动作和多选层复用与当前设置页相同的 `MiuixDialogBuilder`，使用现有 Miuix 字体、圆角、配色、按钮、勾选控件及系统深浅色适配。弹窗尺寸沿用现有宿主边距和安全区域约束。

本地渲染检查覆盖 296 dp 小屏、系统深色但宿主强制浅色、14 项动态视频滚动多选、640×360 横屏实况及返回导航。截图是本地 Compose 渲染结果，不代表真机截图；本地目录为 `artifacts/download-0.1.67-screenshots/`。

## 保存与生命周期

- [OfficialDownloadDialog](../app/src/main/java/com/douai/module/feature/OfficialDownloadDialog.java) 先收集图片、动态视频及实况的原始索引，再生成分类。每个动态视频单独解析其所属图片的 `video`，不复用第一条地址或作品级视频。
- 多选/全部保存动态视频前，检查全部所选来源；任一所选来源缺失时不开始这批保存。未选择的坏来源不会阻止其他有效选择。
- 动态文件命名使用原始图片位置，稀疏选择如第 2、4、5 张仍保留这些序号，文件类型为 MP4。
- 分类切换使用导航令牌，旧窗口回调不能提交新的保存任务。窗口替换不会关闭新层，最终取消、系统关闭、设置改变及页面失效会清理会话。
- 实况仍采用 [0.1.66](release-0.1.66.md) 的共享分类和 [0.1.65](release-0.1.65.md) 的原生编码校验流程，其机型限制与编码取消边界不变。
- 脱敏诊断增加分类数量，仍不记录媒体地址、凭证或作品正文。
