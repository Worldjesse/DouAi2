# DouAi 0.1.97

版本 `0.1.97 / versionCode 98`，基于正式版 0.1.95，纳入 0.1.96 的本地评论回复定位修正。适配抖音 `40.6.0 / 400601`，沿用正式包名 `io.github.yudigaga.douai`、既有发布证书与 R8 配置，资源裁剪关闭。

## 评论回复位置

此前用户日志确认 AI 已生成正文、原生请求已接受，但内容实际发到作品评论区。根因是模块仅绑定目标评论对象，遗漏宿主普通发布分支实际读取的根评论和具体回复定位。原生受理及 `code=0` 均不能单独证明回复到了指定评论。

- 同时填写所属根评论、具体被回复评论和完整原生目标对象，使对方回复我的评论时，发送目标保留为对方的那条回复。
- 新增两条精确宿主规则，调用宿主实际使用的定位解析方法核对有效目标。提交前及完成发送预留后各核对一次，解析结果不一致时停止提交。原始宿主规则共 227 条。
- 保留账号校验、准确成功回执和防重。升级不清空已提交或结果未知记录，不自动补发旧请求。
- AI 仍只使用我的原评论、对方回复及对方评论附图。原作品对象仅供原生发送绑定，不读取其描述、图片、封面或视频用于生成；普通自动评论继续使用自己的素材设置。

根因、原 APK 数据流和修复前回归证据见 [投递目标排查记录](2026-10-19_comment-reply-publish-target-report.md)。旧记录保留 0.1.96 当时的本地验证结果，本版最终验证单独记录如下。原始日志、宿主 APK、`work/` 与 `artifacts/` 均为本地材料，不随公共仓库分发。

## 安装与验收

覆盖安装后完全退出并重新打开抖音，等待新规则适配完成；如提示再次重启则完成该步骤。开启自动回复父开关和接收评论回复子项，保持原有前台、范围、限额及去重条件。

请用新收到的一条回复验证：对方回复我在他人作品下的评论后，自动生成的内容应回复到对方的那条评论。此前发错位置的内容不会自动删除，已提交或结果未知的记录不会自动重发。

旧版的生成与提交已由用户日志确认；本轮没有连接真机、请求真实模型或发送真实账号评论。修正后的实际投递位置仍待手机验证，不能用本地测试或旧版 `code=0` 代替。
