# 0.1.63 发布前复核

审查基线：已发布的 0.1.60 提交 `8de56b64aa680113af511c78dff074f7dc22f5bb`。范围为此后工作区改动及全部新增源码、测试和文档；新增配置导入/导出纳入追加审查。规范与需求分由独立审查者检查，主代理协调修复及验证。

## Standards

未发现文档规范的硬性违反。一个非阻塞的 `possible Duplicated Code` 判断：`AutomationMessageSettingsPage` 与主设置页仍有重复的通用编辑器及普通/Miuix 行构建代码，后续可提取展示控件工厂，同时保留各自生命周期守卫。本次不为此扩大重构范围。

## Spec

发现并复现一个发布前 P2：静止大树中的异步控件插入只触发一次绘制，原先的分片结构检查没有继续请求绘制，可能长期遗漏新目标。新增真实布局/续帧回归后，改为布局事件启动一轮有界续查；保留无变化布局零额外目标发现、每帧预算和关闭清理。

## 追加配置功能复核

- 默认脱敏覆盖认证字段及自定义接口数据，并保持普通回复、提示词等自由文本原样。
- 修复 `maxTokens` 等计数字段误当凭据、参数数组叶值及无等号查询令牌漏出；错误接口字段默认省略。
- 修复模型超 32 位整数在读取时截断的问题，在构造配置前检查原始整数范围。
- 第三方凭据恢复同时绑定 App ID，避免旧 secret 与另一账号配对。
- 通过实际宿主监听/重载交错回归确认失败提交的临时生效窗口，加入稳定快照与最终发布屏障。成功后发布最终配置，失败恢复后保留原配置。
- Android 9/10 的空覆盖只执行 `clear()`，不会产生系统设置变更通知。新增真实 SDK 28 回归后，使用可释放的导入观察者显式发布最终状态，并覆盖配置存储重绑时释放旧观察者和监听的场景。

## 产物与兼容性

复核签名、包名、版本和候选提交文件；APK、私钥、日志、设备材料及本地分析产物均不进入源码提交。旧 APK 保留，配置存储键与类型沿用旧版。未实际备份手机配置，也未验证降级安装；真机项目按用户要求跳过。
