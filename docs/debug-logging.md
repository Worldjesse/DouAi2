# 调试自动行为

入口为 **关于 → 调试与日志**，抖音内设置和独立模块的关于页均可进入。独立模块需要抖音主进程正在运行，不会为了读取日志主动启动抖音。

## 开关与记录范围

| 状态 | 新增日志 |
| --- | --- |
| 关闭（默认） | 启动、真实宿主身份、扫描结果、功能执行结果和错误等简要日志 |
| 开启 | 上述日志，加各功能已注册 Hook 的执行标识、参数类型/数量、结果类型/布尔值、耗时、错误及现有业务阶段日志；自动评论、聊天消息与音频 JSON 快照 |

调试开关实时更新，不重置自动评论、自动回复或消息队列。尚未触发的行为不会出现执行记录。关闭只影响之后的记录，已保存详细日志仍可查看；“清空”才删除现有日志。

自动 JSON 覆盖 Hook 接收到的评论对象、发布响应中的 comment、行绑定参数中的评论、评论读取返回值等。记录 before/after 阶段，用户无需手动打开评论数据窗口。after 表示 Hook 尝试结束，是否抛出异常应结合相邻执行日志判断。它是当时宿主对象的快照，不等同于原始 HTTP 响应；没有自动重新请求网络。

为避免 Context、View 或大对象图无限展开，通用过程日志使用类型摘要；仅识别明确的 Comment、IM Message、AudioContent（含加密音频子类）对象生成 JSON，不递归展开任意对象。音频播放信息、波形、ASR、层级与状态保留，密钥（含音频加密密钥）、Authorization、commentToken、其他令牌及 URL 查询签名在写文件和 LSPosed 前脱敏。评论、聊天快照及关键发送阶段使用独立额度；重复快照去重，达到限流时有计数提示。

`[DouAi.MessageJson]` 自动采集消息/音频在 Hook 边界的快照，可用于区分入队、上传后内容与消息回执；本机成功回执不保证接收端此刻已经能下载播放。当前未采集到接收端播放失败的日志时，不能凭发送成功断言 CDN 或播放器已就绪。`[DouAi.ReplyOverlay]` 记录聊天回复蓝圈阶段、窗口挂载与隐藏原因，不含聊天正文。

版本查询中宿主正常抛出的 `NameNotFoundException` 保持原生语义；详细模式记为 `outcome=package_not_found`，不再当作模块功能失败刷屏。简要评论回执保留结果、错误码与主评论/回复、文字/语音类型，轮询没有新内容不再占用错误摘要。

## 获取自动行为日志

1. 覆盖安装候选包后，完全退出并重新打开抖音。
2. 在“关于 → 调试与日志”打开全局调试。
3. 触发待排查功能；自动评论或回复照常等待自动执行，不需要手动替代发送。
4. 返回调试页刷新查看，或导出保留日志。也可同时导出 LSPosed 日志。
5. 排查结束后关闭调试；需要删除已有内容时点“清空”。

页面提供分类筛选（全部、结果与错误、自动评论、聊天回复、JSON、Hook 与界面）、关键词搜索和当前命中计数。选择“查看条目”可打开一条完整已脱敏记录，格式化查看 JSON 并单条复制，方便对比自动评论与手动评论、发出与收到的音频字段。统计表示日志记录次数，不是去重后的真实消息数；详细模式同一次操作可能包含多个阶段。

刷新、清空、复制和导出继续可用。复制当前筛选后显示文本；导出通过系统文件选择器写 UTF-8 文本，包含完整保留日志，不受筛选影响。浅色与深色主题跟随现有模块主题。

## 容量与实现边界

本地最多保留两份各 1 MiB 的轮转日志；页面显示最近 128K 字符，单条记录上限 256 KiB。队列、突发 Hook 和 JSON 快照都有容量限制，丢弃或截断会标明。LSPosed 的长记录按编号分段，本地文件保留同一脱敏事件，文件容量上限仍适用。

磁盘写入在单独线程执行。模块独立应用通过指定宿主包、签名权限保护的通道读取；完整导出分块取得同一短期快照，不新增公开 provider 或存储权限。宿主未运行或通道不可用时明确显示失败，不用本地空列表冒充已连接。

调试会增加序列化和日志开销；耗时是调试开启时观测到的执行时间。主流程返回值、异常对象、发布重试/成功规则保持不变。没有执行过的设备路径仍需真实设备复核。

## 主动查看一条评论

在“评论相关 → 长按操作”启用“复制源数据”；长按评论打开抖音菜单，再长按其中菜单项进入“评论工具”，选择“查看评论数据”。窗口提供语音摘要、滚动完整 JSON 和主动复制；不影响自动调试记录。

第三方 YuePanel 的捕获/查看/复制功能已做[本地静态分析](../work/comment-inspector-module-20261021/report.md)。DouAi 使用自己的扫描合同、当前行绑定、宿主 Gson 与原生对话框实现，没有复制其授权或网络逻辑。
