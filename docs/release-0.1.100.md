# DouAi 0.1.100 本地优化记录

版本 **0.1.100 / 101**，适配证据仍限定于抖音 **40.6.0 / 400601**。本轮保留工作区已有的 MiniMax 变更，落实 [六批优化计划](optimization-plan.md)。这是本地开发构建，未远端发布，当前正式版仍标注为 0.1.97 / 98。

## 使用变化

- 自动评论与私信在调用宿主前持久化发送预留，使用账号范围身份哈希及独立 attempt token。落盘失败停止发送；未知结果不自动重发、不淘汰，迟到失败不释放未知预留或额度，迟到成功可完成原记录。旧评论去重记录继续保留。
- 私信保持单任务执行、同会话 FIFO，多会话轮转，等待队列最多 100 项。排队与执行各有独立的 120 秒预算；配置的发送延迟仍独立生效。宿主回执结果落盘使用共享、有界后台队列，避免主线程执行这部分同步写入。
- 历史详情增加受控原因、阶段以及排队、媒体、生成、发送确认等待耗时。旧记录缺少的字段保持未知；恶意、未知诊断字符串不会原样展示。Dispatcher 统一管理终态，补原因不覆盖已有时间及媒体信息。
- MiniMax 模型、音色刷新保留安全的具体错误原因和原列表。高级候选提前提示不兼容组合，保存、运行及导入继续共用原校验；不静默修改已有设置。手填未知模型保留并标明高级能力未验证。
- 原生和 Miuix 设置搜索共用 AI、MiniMax、音色、API Key、保存目录、去水印等词条及入口路径，点击只导航。
- 本地分析、下载媒体呈现、原生私信自动回复加入统一能力目录；规则匹配、Hook 安装及实际行为分开报告。诊断增加本次扫描/缓存读取耗时和扫描结束时宿主 Java 堆快照，后者不能单独归因于模块。
- 图表缓存静态绘制命令、命中区域及辅助功能描述。连续重绘和选择只复用稳定内容，尺寸、密度、字体缩放或深浅主题变化时重建，脱离窗口时释放绘制缓存。

## 复现本地验收

需要 JDK 21、Android SDK 37/build-tools、Python 3.10+、既有本机签名配置，以及合法取得的原始宿主 APK 和本地 smali 对照材料。密钥不写入仓库或报告。

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\tools\verify-release.ps1 -HostApk (Resolve-Path '抖音-40.6.0_40609900_20260922 (400601).apk').Path
```

脚本为每次执行创建独立归档目录；锁定构建源码、宿主和最终签名 APK，完整运行全部测试后检查每个源测试方法和实际 JUnit 报告。包括两个独立的嵌套 Miuix 测试类，任何漏测、跳过、失败或证据不一致均不能通过。普通 CI 没有宿主材料时按全部宿主合同分组明确报告跳过，不标为适配已验。

验收参数固定为 Gradle 768 MiB、测试堆 1 GiB、单工作进程、每 20 个测试类回收 JVM，并保存实际参数。JUnit、Lint、R8 mapping、签名、包信息和哈希与机器清单一起归档。Windows `aapt` 读取中文宿主文件名时使用哈希一致的临时副本，成功和失败都会清理；原始宿主继续供合同测试和前后哈希核对。

独立脚本回归：`python -B -m unittest discover -s tools/tests -v`，32 项通过。覆盖缺输入、缺套件/方法、嵌套归属错误、跳过/失败、签名及版本不一致、产物或报告篡改、Lint 新增预算与参数弱化等负例。

## 验证结果

最终严格全量验收已通过：**177 个套件、1843 次测试执行，零失败、零错误、零跳过**。1834 个源码方法及 9 个额外 SDK 变体均有对应报告，两个嵌套 Miuix 套件分别计入。227 条宿主规则唯一性、全部必需宿主合同和最终签名 APK 的 3 项合同检查均包含在本次完整回归中。

机器清单状态为 `verified-local`，`published=false`；源码、宿主和最终 APK 在验收前后哈希一致。归档证据哈希复核通过，最终 APK 的 `zipalign -c -P 16 4` 检查通过，32 项脚本回归日志一并保存。

此前专项已通过发送/历史 207 项、界面/图表 95 项，以及最终私信 47 项与嵌套 Miuix 2 项；这些范围有重叠，不相加作为全量测试数。图表回归覆盖连续 100 次重绘的命中区域复用、像素一致性、选择、尺寸及主题变化。本地渲染截图位于 `artifacts/optimization-2026-10-20/screenshots/` 和 `app/build/reports/local-analytics-screenshots/`，已查看窄屏 MiniMax 与图表渲染。

Release 构建与原证书 v3 签名检查通过；Lint **0 错误、56 警告**，原 9 项 `DrawAllocation` 警告消除。其余警告按类型保留审阅原因，包括发送预留必须同步提交、Hook 必需反射以及依赖/工具链提示；新增中文搜索说明计入显式预算。后续 CI 与严格本地验收均检查预算，不能用总数相同掩盖不同问题键的新增。
