# DouAi 0.1.59

版本 `0.1.59` / versionCode `60`，基于 `0.1.58`。本版修复自动语音评论重复提交并整理文本转语音设置，仅在本地构建，未上传 GitHub 或 LSPosed。

## 更新

- 修复抖音语音评论上传入口返回 `false` 的异步语义：宿主启动音频上传后会等待真实成功或失败回调，不再把异步接管误判为失败重试。实际上传由请求对象、评论模型和源文件路径共同确认，未经上传的真实拒绝仍会失败。
- 自动评论历史列表和详情显示实际发送方式：语音、文本；旧记录显示未记录。
- 开启语音评论时先尝试语音，三次明确失败后复用同一正文发送文本；AI 请求失败仍沿用原有 AI 重试限制，上传结果未确认时不会回退文本。关闭语音评论时只发送文本。
- 语音回退文本使用完整原正文，由抖音发布流程进行最终校验；不重新请求 AI，不重复合成。
- 文本转语音第三方设置参照第三方下载的 GET 配置习惯：主合成保留 GET、可编辑参数、请求头、响应样本和音频地址字段；音色列表直接使用填写的完整 GET 地址，刷新时不自动添加参数。
- 音色列表的请求头、列表字段、编号字段、名称字段和响应样本集中在音色高级设置；主合成请求头与音频字段保持独立。
- 保留第三方下载、保存位置、主页关于和帮助等已有功能。
