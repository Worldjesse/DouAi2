# DouAi 0.1.48

版本 `0.1.48` / versionCode `49`，包名和发布签名保持不变。当前宿主适配为抖音 40.6.0，Release 使用 R8，资源裁剪关闭。

本版为本地修复记录，改动已并入 [0.1.50 正式版](release-0.1.50.md)。

## 修复

- 状态栏控制器提前安装，晚安装补处理当前窗口；窗口焦点恢复时补回隐藏标志，启动仅读取系统栏配置。
- 组件隐藏重新发现晚插入、替换和重绑控件，补齐宿主进度条类型。
- 保留宿主随后设置的显隐以及 `-1/-2` 模式下的淡入状态，避免共享父容器恢复旧的 GONE/Alpha 0 导致进度条消失；从隐藏切为半透明时也保留此前的宿主更新。
- 作者声明 `jb1` 及其仅含声明的匿名背景包装层归入“轻反馈组件”；位置、拍同款、特效、付费视频等新旧锚点容器归入“底部工具”。数字 ID 检查宿主包名和资源名，匿名新版锚点按精确宿主类型识别，不使用宽泛文字或屏幕坐标匹配。
- 修复点击评论历史闪退：原 ListView 会预测量未附着窗口的 Compose 行，触发 `Cannot locate windowRecomposer`。Miuix 历史改为单一有高度上限的 LazyColumn，保留后台读取、虚拟化、详情和清空；原生恢复界面仍使用 ListView。
