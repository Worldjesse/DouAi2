# DouAi 0.2.4 正式版：导入完成反馈与报告分享

**0.2.4 / 105 正式版**沿用包名 `io.github.yudigaga.douai` 和原长期证书，适配抖音 `40.6.0 / 400601`，需要 Android 9+ 与支持 libxposed API 102 的 LSPosed。本轮补充备份导入成功 Toast，并提供独立浅色排版的单张长 PNG 与单份 PDF 报告分享。用户已确认 0.2.3 在手机上可以导入备份；本版新增通知与分享功能仍未进行真机或真实服务验收。

正式下载：[GitHub v0.2.4](https://github.com/yudigaga/DouAi/releases/tag/v0.2.4) · [LSPosed 105-0.2.4](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.douai/releases/tag/105-0.2.4)。可从既有正式版覆盖安装，安装后完全退出并重新打开抖音，等待适配完成。

## 本次正式发布的累计更新

本版汇总 0.1.97 之后的本地变更，历史版本的独立归档及验证范围继续保留：

- **MiniMax 语音**：独立的服务地址、API Key、模型及音色设置；可主动刷新账户音色、接口模型或官方目录，保留手填。增加按能力校验的情绪、语言、格式、采样率、码率、声道与声音效果等高级选项。试听、手动转语音和自动化共用所选来源。见 [0.1.98](release-0.1.98.md)、[0.1.99](release-0.1.99.md)。
- **发送与历史**：自动评论及私信增加发送前持久化预留，账号隔离、落盘失败停止发送、未知结果保留防重。私信保持同会话顺序并按会话轮转，区分排队和执行预算；历史显示受控原因、阶段和耗时。见 [0.1.100](release-0.1.100.md)。
- **设置与诊断**：MiniMax 刷新移入选择弹窗，普通表单、提示词及聊天共用局部编辑，完善设置搜索和能力诊断。未保存的发送预览超时默认 3 秒，保留已有保存值；语音失败补充受控数值码与上传/发布阶段。见 [0.2.1](release-0.2.1.md)。
- **备份与本地报告**：完善受控导入诊断，修复 Android ICU 占位符正则兼容性，成功应用备份后显示一次通知；报告展示完整已有 AI 结果，并支持独立浅色版式的长 PNG 或 A4 PDF 导出。见 [0.2.2](release-0.2.2.md)、[0.2.3](release-0.2.3.md)及下文。
- **发布验证**：新增锁定源码、宿主和最终 APK 的严格入口、完整测试清点、Lint 增量预算、原生 ICU 门禁及封存完整性复核；普通 CI 明确列出缺少宿主材料的检查。复现方法见 [正式构建](releasing.md)。

上述本地测试不证明真实语音成功率或手机输入性能提升。用户提供的旧版语音日志另有成功和失败样本，结论及限制保留在 [语音现场记录](voice-2026-10-21.md)中。

## 备份恢复与完成通知

0.2.3 针对 Android ICU 占位符正则的修正现已有用户手机恢复反馈。该证据来自用户安装后的实际反馈，不是代理连接设备执行的测试；[0.2.3 交付记录](release-0.2.3.md)中“交付时尚未验证手机恢复”的状态保留为当时事实。

本轮通知契约为：只有用户确认后，`ConfigBackup.apply` 实际成功，才在主线程使用宿主 application context 显示一次“备份导入成功”。通知先于可能关闭或重建设置页的 `changed` 回调，原有详细状态文案与受控校验诊断保留。预览、取消、失败、导出和已关闭页面的晚回调不显示导入成功。

原生产代码的 Toast 专项 5 项实际执行，成功通知主契约 1 项失败，其余 4 项取消/失败/过期回调守护通过，归档 `work/evidence/toast-report-ui-red-0.2.4/testDebugUnitTest/`。源码现已补充固定安全文案的原生 Toast；平台通知若抛运行异常，只记录固定不可用标记，不妨碍已成功的导入或刷新回调。新增平台异常守护后，**6 项专项全部通过，0 失败、0 错误、0 跳过**，结果在 `work/evidence/report-file-red-toast-green-0.2.4/testDebugUnitTest/` 的 `ConfigTransferToastTest` XML；同批报告后端红测不算作 Toast 失败。

## 报告新需求

报告改用独立浅色纸张排版，可选择单张长 PNG 或单份 A4 分页 PDF。内容包括统计、图表、排行、最近记录、采集边界与已有 AI 分析，导出不会再发起 AI 请求，也不会重新排列当前页面。PDF 为图片型页面，不支持选择文字；原有“分享分析文字”入口保留。

Android 10 及以上将 PNG 保存到 `Pictures/DouAi`，PDF 保存到 `Downloads/DouAi`；Android 9 使用系统单文件保存入口。长图超限时提示改用 PDF，PDF 仍超限则需缩小范围，不静默裁掉后文。生成失败、取消或过期操作的未完成文件在后台清理；分享面板打开后保留已完成文件。切换范围、清空记录、重新分析或关闭报告会取消旧操作，旧结果不会归入新范围。报告可能包含可见作者、话题、最近记录与 AI 分析，分享前应自行核对。

阶段性预检已实际执行 **11 类、151 项，0 失败、0 错误、0 跳过**，覆盖备份、Toast、选择器、报告界面与导出后端，JUnit 位于 `work/evidence/report-toast-preflight-0.2.4/junit/`。工具测试另有 **34 项通过**。这些结果产生于随后 PDF 分页及 Lint 定点修改之前，不能替代最终源码完整验收。
