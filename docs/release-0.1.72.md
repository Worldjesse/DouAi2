# 0.1.72：自动回复素材识别与独立悬浮提示

版本 `0.1.72 / 73`。自动回复新增与自动评论一致的「素材识别」入口；私聊、群聊和评论回复共用父级配置、模型和提示词。

相对于已发布的 0.1.69，本版包含评论回复接入及父级设置合并，历史实现与验证见 [0.1.70](release-0.1.70.md) 和 [0.1.71](release-0.1.71.md)。当前评论回复由自动回复父开关和「接收评论回复」共同控制，使用父级模式、提示词、语音、额度和历史，不使用首版独立配置页。

## 使用

1. 在「自动回复 → 回复模式」选择「AI 模型」。
2. 打开「素材识别」选择图片或视频。图片默认开启，视频默认关闭；两项均需当前模型支持图片输入。
3. 在「发送与记录」启用「悬浮提示」，按需设置提示超时。自动回复使用蓝色环形提示，自动评论保留青绿色；两者位置分别保存。
4. 设置行只保留名称、当前值和开关，解释移至内置帮助及 [帮助文档](help.md)。必要动态状态、错误和操作确认仍正常显示。

## 素材来源

| 接收渠道 | 支持范围 |
| --- | --- |
| 私聊、群聊 | 开启图片识别时读取受支持的收到图片；关闭后不读取图片，附带真实文字可以按文字回复 |
| 评论回复有对方附图 | 优先仅读取对方评论附图，不混入原作品、本人原评论或头像 |
| 评论回复无对方附图 | 根据已选开关读取捕获的关联作品图片/封面及视频抽帧，不跟随当前 Feed 作品变化 |
| 视频 | 关联作品的真实视频地址下载后抽帧，不读取声音；私聊/群聊原视频的加密解析暂未适配，直接跳过 |

每次请求最多 4 张图片或视频帧；图片与作品视频同时启用时，最多保留一张图片并为视频帧留出名额。关闭图片识别时不会因为没有封面而额外下载视频。固定内容、关键词和随机模式不读取素材，切换模式保留原来的选项值。

图片已启用但地址无效、下载或解码失败时不会假装已识别，也不静默改成空视觉请求；评论附图失败时不改用作品画面替代。修改素材开关会取消尚未提交的任务、断开读取并清除模型上下文中的旧图；迟到的旧发送确认不会重新带回已清除的图片。

纯图片评论来评只在 AI 模式、图片识别已开启且拿到真实附图时处理；原评论文字、本人身份、作品、根评论及父目标仍须可核实。首次启用不追发旧评论的规则保持。

## 独立悬浮提示

私聊、群聊和评论回复汇入同一个蓝色回复环，与青绿色评论环分别显示队列和当前阶段。点击查看详情、暂停倒计时并核对输入与正文；长按取消尚未提交任务，详情中可以立即发送或取消。已提交或结果未知的任务只显示状态，不据此重复发送。两个悬浮环可以分别拖动并记住位置，页面离开或关闭功能时清理显示。
