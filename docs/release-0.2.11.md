## 使用

在 **评论相关** 主页面开启 **#长按发送转语音（全局）**。该开关与“评论转语音”入口并列，默认关闭，覆盖私信、群聊、评论和评论回复。输入 `#内容` 后长按原生发送按钮，将去掉开头的 `#` 合成为语音，仅发送语音；失败保留草稿并提示，不回退发文字。没有 `#` 或关闭开关时保持原生长按行为。原有评论、私信单击转语音设置继续独立生效。
