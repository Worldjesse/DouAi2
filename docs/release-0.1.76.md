# 0.1.76：在抖音消息页与 AI 模型对话

本地版本 `0.1.76 / 77`。在 AI 模型编辑页开启“加入抖音消息界面”，即可从抖音消息页打开该模型的对话。联系人入口和媒体识别的真实服务效果尚未进行真机验收；本轮未发布 GitHub 或 LSPosed Release。

## 使用方法

1. 在“扩展功能 → AI 模型设置”编辑已配置的模型，开启“加入抖音消息界面”。
2. 填写联系人名字，选择头像并保存。名字留空时使用配置名称，头像可恢复默认。多个模型可分别加入消息页。
3. 返回抖音消息页，点击 AI 联系人开始对话。附件按钮可添加图片、视频或文件；支持停止请求、失败重试和清空聊天。
4. 对话页的编辑按钮可修改联系人配置。这里保存名称、头像不会切换自动回复使用的当前模型；保存后重新打开联系人即可使用新设置。

消息对话和测试对话使用不同的私有历史目录。每个模型保留最近配置轮数的对话与附件上下文，范围为 0 至 50；设为 0 时不保存历史。修改名字、头像不清空消息对话。模型协议、接口、模型名或一级提示词改变时使用不同的历史身份。历史和图片缓存有容量上限。

## 文件、图片和视频

| 类型 | 提供给模型的内容 | 限制 |
| --- | --- | --- |
| 图片 | 解码并压缩后的图片 | 与 PDF 页、视频帧合计每条最多 4 张，需支持视觉输入的模型与接口 |
| UTF-8 文本、Markdown、CSV、JSON、代码等 | 文件正文 | 源文件最大 1 MB，每个文件最多 16000 个字符 |
| DOCX | 正文文字 | 文件最大 16 MB，每个文件最多 16000 个字符，不包含嵌入图片和原始排版 |
| PDF | 从第一页开始渲染的页面图片 | 文件最大 16 MB，按剩余图片名额读取，最多 4 页 |
| 视频 | 按时间顺序抽取的画面、时长和目标抽样时间 | 文件最大 64 MB，不包含音频或未抽取的片段，不能代替完整视频理解 |

每条消息最多 4 个文件或视频说明，附件文字总计最多 32768 个字符。移除 PDF 或视频时会一起移除该附件的页面/帧与说明；混合发送时，说明中的图片序号会按实际发送顺序重新计算。后续上下文保留采样范围，避免把抽样图片当作完整视频。

## 消息页适配

只在已识别且可见的抖音消息 Fragment、唯一原生会话列表和受支持的父容器中添加联系人区域。保留原列表的 ID、类型、直接父容器及原生兄弟约束；关闭入口或切换页面时恢复模块持有的间距。联系人区域内部可滚动，小窗口中最多使用可用消息区域的一半。

布局参数使用独立的 ConstraintWidget，避免与宿主共享求解状态。保存配置通过偏好监听立即更新入口，系统深浅色切换通过既有 ModuleTheme 更新。静态证据和真实 ConstraintLayout 本地测量见 [适配记录](2026-10-17_reverse-ai-message-contacts-report.md)。
