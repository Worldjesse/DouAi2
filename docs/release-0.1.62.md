# DouAi 0.1.62

版本 `0.1.62` / versionCode `63`，基于本地 `0.1.61`。本版完成优化计划剩余第 3–5 批，并保留前两批的自动回复与语音修复。沿用正式包名、长期签名和 R8 配置。本版仅本地构建，未上传 GitHub 或 LSPosed；按用户明确要求，全部跳过真机验证。

## Feed 检查成本

隐藏目标的身份与样式仍在每帧维护。结构检查改为每个监视器每次绘制最多 256 个节点，循环覆盖已捕获视图树；无实际变化的布局通知不再强制重新发现目标。小树仍在一帧内检查完，大树最多 16 个绘制回调覆盖捕获的 4096 个节点。结构、ID、内容和声明容器背景变化仍能触发发现，未接管宿主的层级监听器。

使用 Robolectric 固定树和固定绘制次数记录的结果：

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 1026 节点卡片，300 帧结构节点检查 | 307,800 | 76,800 |
| 窗口自定义目标，300 帧结构节点检查 | 309,600 | 77,100 |
| 卡片 30 次无变化布局的额外发现 | 30 | 0 |
| 窗口 30 次无变化布局的额外发现 | 90 | 0 |

两类大树结构检查工作量减少约 75%。这些数字不是帧耗时或 FPS，不代表已测得真机流畅度、耗电或内存改善。大树中尚未缓存的新目标可能需要等待一次有界扫描；已经缓存的目标仍每帧恢复样式。

## 下载任务与取消

- “下载相关”增加“下载任务”，显示当前文件、字节进度、文件数及排队、下载、取消中、完成、失败、超时等状态。普通界面与 Miuix 共用任务状态，列表按可见行渲染。
- 官方模块保存与第三方作品包共用 2 个工作位、16 个等待位。每项任务从开始执行起使用 30 分钟整体时限，覆盖第三方解析、媒体和元数据；单个媒体仍限制为 512 MB。
- 排队取消立即释放等待位及去重键；进行中任务先取消传输并清理本次未完成输出，再释放去重键。重复提交与队列满保持明确提示。
- 取消点击立即标记状态，可能阻塞的断连、输入/输出流关闭和系统下载移除交给有界后台处理，不在界面线程等待。保存失败只清理本次创建的 MediaStore/SAF 记录或旧版目录，不删除原有文件。第三方作品包保持整体成功或清理的语义。
- Android 9 默认官方保存保留 DownloadManager，跟踪本次任务 ID 的进度及结果，取消/失败仅移除该 ID。自定义目录和第三方作品包沿用相应保存路径。
- 任务页关闭会退订刷新，不停止下载；保留所有活动任务及最近 50 条结束记录，不保存到磁盘。任务列表与错误摘要不展示解析地址、鉴权头或密钥。
- 抖音完全原生的下载未改由此任务页接管。页面只显示由 DouAi 保存的任务。

## 回复与评论设置

`AutomationMessageSettings` 集中范围快照、旧配置迁移、输入校验和编辑会话；`AutomationMessageSettingsPage` 独立管理回复、评论及其子表单。主设置保留导航和生命周期登记，不再借用共享表单容器构建这些子页。

启停会读取最新完整配置后更新所属字段，避免覆盖页面打开后其他功能的修改。旧配置键、源数据和默认行为保持；关闭页面后旧开关、旧编辑器及迟到回调不能继续写入。子表单依所属对话框是否仍显示判断有效性，不把 Android 控件附着时机当作配置写入条件。
