# DouAi 0.1.56

版本 `0.1.56` / versionCode `57`，基于 `0.1.55`。沿用正式包名、长期发布签名和 R8 配置。本版只在本地构建，尚未上传 GitHub 或 LSPosed。

## 改动

- 扩展功能的文本转语音设置支持系统引擎与第三方 GET 二选一，按选择显示设置；原有引擎、语言、语速和音调继续使用原配置。
- 合成 GET 的参数名和值可编辑、增删，支持无参数地址；待合成文本和已选音色可绑定到任意参数或地址路径。保存 GET 后自动更新参数显示。
- 第三方响应支持直接音频、JSON 音频字段和 TXT 音频链接；默认音频字段为 `url`，字段路径可编辑。
- 音色列表使用独立 GET 和请求头，支持编号 TXT、JSON 数组与编号映射，以及可配置的列表、编号和名称字段。支持刷新、粘贴样本、选择和手填音色。
- 试听使用当前语音来源和音色。修改设置、关闭页面或重新试听会取消旧请求，忽略旧回调并清理缓存。
- 自动回复（已启用的私聊和群聊）与自动评论分别提供语音开关，默认关闭。开启后只提交音频；生成失败不回退文本。评论语音最长 30 秒，消息语音最长 120 秒。
- 语音在进入自动化发送倒计时前生成并转为原生 AAC。发送仍经过已配置的对象范围、账号校验、发送确认和限额控制。语音设置变化会取消未提交的任务。
- 原生消息的本地入库和上传排队不记为发送成功；须收到成功状态、服务器消息 ID 和成功状态码。未确认上传的音频保留至十分钟清理期限，迟到的入库回调不能上传已清理的文件。
- 自动语音评论沿用捕获作品的原生发布流程，文字与文字附件为空。失败重试复用音频，成功回执后清理；已有的评论语音替换选项不会覆盖模块生成的音频。
- 手动 `#` 文本转语音也使用当前语音来源，取消、转码任务拒绝和未入队时清理未移交的文件。
- 保留此前的官方/第三方下载互斥选择、自定义保存目录、手势菜单下载，以及媒体和整理后的 TXT 同目录保存。

## 本次接口配置

用户提供的合成 GET 对应默认模板：

```text
http://www.yx520.ltd/API/wzzyypromax/api.php?voice={voice}&apikey=YOUR_API_KEY&text={text}
```

`YOUR_API_KEY` 须替换为用户的实际密钥；默认保存值中的 `apikey` 为空。参数名和值均可改成其他 API 所要求的形式，不固定要求 APPID。

音色列表默认 GET：`https://www.yx520.ltd/API/wzzyypromax/ys.php`，无需查询参数。公开 GET 返回 `text/plain; charset=utf-8`，本次读到 223 项音色；`1. 叶修` 解析为编号 `1` 和名称 `叶修`，选择后只把编号代入 `{voice}`。编号 TXT 不需要填写 JSON 字段路径。用户提供的合成 JSON 默认从 `url` 获取音频。

请求头默认 `{}`。只有接口要求额外请求头时才填写 JSON 字符串键值对象；合成请求与音色请求分别配置。主 API 的请求头不会携带到不同来源的音频地址。
