# DouAi 0.1.95

版本 `0.1.95 / versionCode 96`，适配抖音 `40.6.0 / 400601`。沿用正式包名 `io.github.yudigaga.douai`、既有发布证书与 R8 配置，资源裁剪关闭。本版汇总此前 0.1.83 至 0.1.95 的本地变更；各轮报告继续保留当时的证据和验证边界。

## 评论回复

- 修正通知分页的双游标、零游标和空页兼容，使用宿主实际“收到评论”分组；重复停滞、页数和时间预算继续有界。
- 通知缺少上下文时，查询本人原评论与对应真实回复线程，严格核对来评、发送者、作品、根评论与直接父评论。保留账号核验，拒绝明确回复其他人或身份冲突的目标。
- 将宿主混淆后的 Task 等待、错误读取与结果方法纳入精确适配规则；保留限时等待、取消和中断。
- 评论回复的模型输入仅使用“我的原评论”“对方的回复”及对方评论附图，不再读取原作品描述、图片、封面或视频。没有附图时直接使用双方文字；附图仍受图片开关、数量、来源校验和取消约束。
- 用于原生发送的作品及评论对象继续绑定到正确线程，但不作为 AI 输入。普通自动评论仍使用自己的作品素材设置。
- 增加媒体、输入、模型、输出、语音、调度和提交阶段的脱敏诊断，区分请求写出、生成完成、原生受理和准确成功回执，不输出正文、URL 或凭据。

处理版本为 4，保留原始起点、发送去重、已提交和结果未知记录。升级不会清空已达到失败次数上限的记录；建议用新收到的一条评论回复验收。通知匹配完成不等于 AI 已生成，更不等于原生回复已成功发送。

相关证据：[回源核对](2026-10-19_comment-reply-thread-backfill-report.md)、[Task 合同](2026-10-19_comment-reply-task-await-report.md)、[阶段诊断](2026-10-19_comment-reply-generation-diagnostic-report.md)、[评论素材修正](2026-10-19_comment-reply-comment-media-report.md)。原始日志、宿主 APK、`work/` 和 `artifacts/` 均为本地材料，不随公共仓库分发。

## 模型与本地分析

- 每个模型可选择流式或非流式响应，测试对话、消息联系人、自动回复、自动评论和本地分析使用相应模型设置。完整接收并校验后才展示或发送，不把未完成片段当成最终正文，失败时不自动切换响应方式重发。
- 推理强度保留“模型默认”，按协议提供原始候选值；候选不等于当前模型或中转已验证支持，需与高级参数中的同类设置避免冲突。
- 本地分析改善完整流式结果和结构校验诊断，统计摘要受 16000 字符及 32768 UTF-8 字节预算约束；日常统计仍只在本机，主动点击 AI 分析才发送有界摘要。
- 分析页面统一 Miuix 弹窗与折叠区块。配置备份可选择包含本地分析数据，默认不包含；恢复分析需另行确认替换，采集开关保留本机状态。备份是明文 JSON，应妥善保存，选择包含密钥或分析数据后尤其如此。

详细说明：[分析备份](release-0.1.83.md)、[分析诊断](release-0.1.84.md)、[流式与摘要预算](release-0.1.85.md)、[模型响应方式与推理强度](release-0.1.86.md)。

## 安装与边界

从既有正式版覆盖安装后完全退出并重新打开抖音，等待新规则适配完成；如提示再次重启则完成该步骤。评论回复仍需开启自动回复父开关与接收评论回复子项，并遵守原有前台、范围、限额及去重条件。

本轮没有连接真机、请求真实模型或发送真实账号评论。已有用户日志用于定位旧版失败，不能作为新版生成、提交或可见性验收。需要分别核对新版本的线程匹配、AI 请求、生成、原生受理和成功回执。
