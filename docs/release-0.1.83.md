# 0.1.83：本地分析界面统一、内容收纳与可选备份

版本 `0.1.83 / versionCode 84`。本轮本地交付，沿用 0.1.82 的统计口径、人物侧写与主动 AI 请求行为。

本地数据分析从“扩展功能”打开时，使用与模型设置、语音设置、配置备份一致的 Miuix 弹窗和表单控件。统一标题、关闭按钮、记录开关、时间范围选择、操作按钮、输入与确认弹窗，以及卡片间距和文字层级。原有恢复界面仍使用相应的原生控件。

侧写和图表使用统一的中性色标题与说明文字，数据系列保留各自的语义色。查看依据、切换范围、采集开关、清空、自述、反馈、AI 分析和分享的行为继续保留，界面跟随系统深浅色。

报告内容区块支持展开、收起，默认简洁展示；展开后查看图表、详细记录和该图对应分析。

配置备份新增“包含本地分析数据”，默认不勾选。选中后导出保留的统计、关联、自述与反馈；导入时另外选择恢复分析，并明确替换当前分析数据，与配置合并/覆盖独立。采集开关保持本机状态；普通配置及旧备份不影响分析记录。

普通配置保持原格式与 2 MiB 上限；包含分析时使用受限逻辑快照，完整文件上限 32 MiB，分析部分上限 30 MiB / 250,000 行，超限拒绝导出或导入。恢复采用 SQLite 事务，设置与自述失败时补偿；三个存储不构成跨文件的崩溃原子事务。取消、换文件、重复及迟到的文件选择结果均按选择世代隔离。

入口：抖音设置 → DouAi → 扩展功能 → 本地数据分析。
