# DouAi 0.1.53

版本 `0.1.53` / versionCode `54`，基于 `0.1.52`。沿用正式包名、发布签名、R8 配置和抖音 40.6.0 适配规则。

相对于已发布的 0.1.51，本版同时包含 [0.1.52](release-0.1.52.md) 的每日评论/回复上限、同一用户间隔和持久化额度。两项功能独立计数，默认 0 为不限制，清除历史不会重置额度。

## 评论历史的图片请求标记

自动评论的历史详情新增图片请求一行，记录的是客户端实际完成模型请求体写出的证据。

| 显示 | 含义 |
| --- | --- |
| 已携带 N 张图片 | 本次任务的模型请求体已写出，其中含 N 张图片数据 |
| 未携带图片 | 模型请求体已写出，其中没有图片数据 |
| 未确认发送 | 没有观察到模型请求体完整写出的事件，可能使用固定内容、尚未请求或请求失败 |
| 未记录 | 旧历史没有保存请求图片数，不能根据评论文字补推 |

即使模型尚未返回、任务被取消，已发送的图片请求标记仍然保留。状态从待提交变为发送中、成功、失败或取消时不会丢失元数据；清空记录后，迟到的事件不能恢复记录。

图片数量包括图文图片、视频封面或视频采样帧。标记证明客户端提供了图片，不证明模型或接口代理确实理解了画面，也不自动生成图片内容描述。

新日志在请求写出后增加 `Automatic comment model request sent; images=N; work=作品ID`，便于与历史详情的作品标识关联。不会打印图片数据、接口凭据或完整模型请求体。
