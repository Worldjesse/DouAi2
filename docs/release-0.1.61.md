# DouAi 0.1.61

版本 `0.1.61` / versionCode `62`，基于 `0.1.60`。本次交付优化计划的第 1、2 批：自动回复取消与超时、系统语音参数一致性、语音适配诊断。沿用正式包名、发布签名、R8 配置和抖音 40.6.0 适配规则。本版仅本地构建，未上传 GitHub 或 LSPosed。

## 更新

- 自动回复图片读取启动 60 秒整体截止时间。每条回复持有独立的媒体取消状态与生成任务；关闭回复、修改相关设置、关闭模块实例或切换账号后，主动断开旧媒体连接并取消旧任务。账号检查不依赖下一条消息到来。
- 达到用户设置的回复延迟后，排队与生成共用 120 秒截止时间，覆盖图片、AI 请求和语音准备。超时报告失败，迟到音频清理后不发送；将结果交给预览前同步检查截止时间，避免主线程定时检查延迟造成漏判。已经交给预览或原生发送流程的结果继续按原有确认语义处理。
- 续火花定时任务使用独立的单线程调度器，避免被回复媒体下载或语音准备阻塞。发送仍受账号、配置代次和原有发送锁约束；旧回复不能取消下一条回复的 AI 请求。
- 系统语速与音调统一使用 `SpeechSettings` 解析，默认 1、有效范围 0.5 至 2。新输入拒绝越界、非数字和非有限值；旧异常值显示实际有效值，打开页面不改写旧配置。试听与正式合成使用同一结果，第三方语音行为不变。
- 统一适配目录增加评论文本转语音、私聊文本转语音，报告具体规则缺口及安装失败。支持 Android 和 JDK 的字段、构造器、方法、类加载异常格式，只保留类成员契约，不保留媒体地址、任意异常正文或 DexPathList 路径。
- 两个语音 Hook 完成初始化后才发布实例，失败关闭临时实例，成功清除旧错误。Hook 安装状态不代表实际发送成功。
- 应用内帮助与仓库帮助同步更新。

复验命令（PowerShell，JDK 21 和 Android SDK Platform 37）：

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"

$env:DOUAI_VERIFY_RELEASE_APK = (Resolve-Path 'app/build/outputs/apk/release/app-release.apk').Path

```

## 验收边界

本次按用户确认交付本地验证包，不等待真机反馈。未安装到真机、未使用真实账号发送、未调用付费模型或语音接口；不将该交付确认记成真实发送测试通过。
