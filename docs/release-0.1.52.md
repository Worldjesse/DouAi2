版本 `0.1.52` / versionCode `53`，基于 `0.1.51`。沿用正式包名、发布签名、R8 配置和抖音 40.6.0 适配规则。

本版为本地修复记录，改动已并入 [0.1.53 正式版](release-0.1.53.md)。

## 设置

在自动评论和自动回复各自的主列表中配置以下两项，两个功能独立保存设置、独立计数。

| 列表 | 每日上限 | 同一用户间隔 |
| --- | --- | --- |
| 自动评论 | 每日最大评论数 | 同一作者评论间隔（分钟），按作品作者 UID |
| 自动回复 | 每日最大回复数 | 同一用户回复间隔（分钟），按消息发送者 UID |

默认值均为 `0`，表示不限制。每日上限可设 `0..1000000`，间隔可设 `0..525600` 分钟，只接受整数。例如评论上限设为 50、间隔设为 30，同一天最多提交 50 条自动评论，对同一作者至少间隔 30 分钟。现有同一作品去重仍然有效。

## 计数规则

- 按当前登录账号和功能分开计算。每日额度按手机本地自然日重置，用户间隔跨午夜继续计时。
- 回复按实际消息发送者计算，同一发送者在私聊和群聊共用回复间隔；不同群成员不会因为群会话相同而互相占用间隔。
- 原生发送前检查并同步保存占用额度；并发、排队任务不能绕过最后一次检查。已发送或结果未知的提交占用额度，明确失败或确认没有发出的请求释放额度。
- 已进入原生评论提交后抛错，按结果未知处理，保留额度并等待可能的迟到回执，避免直接重试。
- 额度独立于可选的历史记录，关闭或清除历史不会重置额度。重启抖音后继续生效。
- 从本版开始记录提交；当天先发送再开启限制，也会计入已有提交。升级前旧版本的发送不追溯计数。

## 使用

覆盖安装本地 APK 后完全重启抖音，在对应列表设置上限和间隔。达到上限或间隔未满时跳过新的自动任务；到期后由后续消息或作品选择再次触发，不补发已跳过的任务。
