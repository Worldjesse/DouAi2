# DouAi 0.1.47

版本 `0.1.47` / versionCode `48`，正式包名 `io.github.yudigaga.douai`。支持 Android 9+、libxposed API 102，当前适配抖音 40.6.0。

## 更新

- 正式 Release 启用 R8，保留模块入口、成员和宿主反射契约，资源裁剪继续关闭。
- 扫描缓存读写失败可降级为完整扫描，缓存保存失败不丢弃已完成结果。
- 自动评论队列的取消操作在队列调度器中执行；媒体读取可取消，限制读取时长并校验媒体来源。
- 媒体下载队列限制容量并去重，续火花账本区分成功、失败和结果未知，未知结果需确认后才能重试。
- 配置从同一份快照解析，同轮多键通知合并，修复倍速和关系筛选变更未传递给全部消费者的问题。
- 宿主版本、资源契约与适配诊断集中管理；组件隐藏缓存处理目标失效和异步插入。
- 历史和测试对话后台加载，模型编辑器与互动自动化弹窗拆分，关闭页面可取消请求。
- 增加 GitHub CI，验证普通测试、Release Lint 和打包契约；未提供宿主 APK 时明确报告 DEX 集成测试未执行。

## 更新方式

从 0.1.46 正式版直接覆盖安装，在 LSPosed 中保持只勾选抖音，完全退出并重新打开抖音。此前使用 `com.douai.module` Debug 包的用户应先卸载旧模块，避免两份模块同时 Hook。

[源码](https://github.com/yudigaga/DouAi) · [LSPosed 模块仓库](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.douai)
