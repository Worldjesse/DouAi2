# DouAi 0.2.7 正式版：抖音 40.6.0 / 40.8.0 双版本适配

**0.2.7 / 108 正式版** 基于 0.2.6 / 107 源码，同时支持抖音 **40.6.0 / 400601** 与 **40.8.0 / 400801**。最终签名包严格本地验收已完成：**191 套件、2037 次执行，0 失败、0 错误、0 跳过**；同一签名 APK 的 40.6 原宿主兼容复验另有 61 项通过。本版手机、平台模拟器与真实服务尚未执行验收。

正式下载：[GitHub v0.2.7](https://github.com/yudigaga/DouAi/releases/tag/v0.2.7) · [LSPosed 108-0.2.7](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.douai/releases/tag/108-0.2.7)。沿用正式包名与长期签名，可覆盖安装；安装后完全退出并重新打开抖音，等待规则适配完成。

## 本次正式发布的累计更新

本版包含 0.2.4 之后的三轮本地变更，历史归档继续保留各自的产物和验证范围：

- **发送状态核对**：自动评论与私信回复历史增加按当前账号查看发送账本的入口。此前进程留下、至少两分钟且尚未确认成功的记录可二次确认后标记成功或解除预留；核对仅更新本地状态，未知与损坏记录继续保留防重。评论回复扫描记录单独管理。见 [0.2.5](release-0.2.5.md)。
- **设置与加载**：补齐账本容量/存储状态与后台持久化，成员头像使用独立的按尺寸解码、请求合并和取消路径；统一配置目录与 21 项设置搜索，下载设置可定位并短暂高亮具体行。上述本地回归不代表手机帧率提升。见 [0.2.5](release-0.2.5.md)。
- **隐藏视频保护**：补充安全校验当前项、非当前项自动移除任务的保护，在任务执行时读取开关，并显示安装状态与命中计数；保留两版本各自的任务分支合同。手机提示与该链的现场关联及内容可播放性仍待验证。见 [0.2.6](release-0.2.6.md)及下文。
- **双版本适配**：按真实安装 APK 选择独立规则、资源和反射别名；迁移 40.8.0 的 Feed、聊天、相册、私信与语音上传合同，同时保留 40.6.0。语音继续使用既有生成、时长、重试及回退策略。

0.2.5、0.2.6 的三项 Android 15 模拟器平台合同属于各自当时的 Debug/测试 APK，覆盖合成备份与报告文件，不能作为本版 40.8.0 Hook 或手机发送已验收的证据。平台方法与限制见 [Android 平台烟测](platform-validation.md)。

## 本轮变化

- 同一签名APK携带两套独立规则、资源与反射别名，直接读取真实安装包Manifest选择，版本伪装不会切换适配。40.6原始规则从0.2.6归档完整保留，未知版本不默认套用40.8。
- 迁移229条宿主规则，40.8原APK扫描从145唯一/84缺失变为229唯一/0缺失/0多候选，40.6独立规则仍为229唯一；日志中旧0.2.4使用227条规则，结果为145/82，差额来自0.2.6新增保护。
- 按原/新APK控件结构迁移51项Feed资源，以及原生聊天根布局、输入栏、快捷入口、气泡和头像资源。直接解析原APK资源表核验ID/name，避免按相同混淆名误迁移。
- 更新原生聊天、头像加载、相册参数、语音上传与消息/评论混淆目标。统一版本门禁；底部导航使用扫描类名，保留View类型与唯一性检查。
- 隐藏视频保护保留两版合同：40.6使用原当前分支`t=0`与独立后台任务；40.8共享任务仅拦当前`t=1`、后台`t=0`，其他popup/删除/重试分支放行。开关关闭或安装合同异常时保留宿主行为。
- 语音回调参数传入顺序变化已按原DEX核对，字段仍为`l0=model/l1=request`，保留异步上传受理语义及现有时长、生成、重试与回退策略。

分析范围、日志时间线、证据链及复现方法见 [40.8.0 适配记录](2026-10-21_douyin-40.8.0-adaptation-report.md)。0.2.6归档独立保留；0.2.7继续支持40.6.0，新增40.8.0。
