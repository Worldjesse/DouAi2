# DouAi 0.2.13 正式版：配置入口与音频导入

正式版 **0.2.13 / 114**，包名 `io.github.yudigaga.douai`，沿用长期证书、R8 压缩和不可调试的 Release 配置。需要 Android 9+ 与支持 libxposed API 102 的 LSPosed。

正式下载：[GitHub v0.2.13](https://github.com/yudigaga/DouAi/releases/tag/v0.2.13) · [LSPosed 114-0.2.13](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.douai/releases/tag/114-0.2.13)。可覆盖安装，安装后完全退出并重新打开抖音。继续支持抖音 40.6，40.8 仅支持真实内部构建 **40809900**。

## 配置与文件导入

- **语音文件独立配置**：“评论语音文件”和“私聊语音文件”持续可见，可先配置再开启替换，也可在替换已开启时重新选择。选择器导入到草稿，只有点击“保存”才写入路径；取消、关闭或过期结果保留原设置，未保存的导入副本会清理。导入期间暂停保存，系统选择器取消后可继续编辑。
- **直接找到设置**：评论与消息页均提供文本转语音设置入口；“长按操作”改为点击后多选复制评论、保存评论图片和复制源数据，设置行显示已选项。补充评论/私聊语音文件的搜索入口。
- **群会话 ID 手填**：群聊白名单和黑名单均可手动填写会话 ID，没有缓存群列表也能配置；仍可从已读取的群列表选择。取消、关闭或过期编辑保留原选择。
- **模型可选参数**：温度、最大输出 Token、Top P 未启用时禁用对应输入并保留已有值，未启用输入中的无效草稿不再阻止保存；启用后仍按原规则校验。
- **说明与标签**：筛选使用“整页筛空时保留原列表”“最长时长（秒）”“最低点赞数（0不限制）”“屏蔽关键词”；下载中的“默认行为”更名为“直接保存全部媒体”。澄清互动自动化总开关与“立即停止”的范围，移除自动评论的错误暂停提示。配置键和已有保存值继续沿用。

官方下载与第三方下载继续按当前所选方式工作，共用保存位置。音频路径的导入与草稿提交属于配置流程；实际音频替换仍需开启对应开关并满足原有文件与宿主要求。此前调试日志修复、长按转语音和语音格式功能继续保留，历史说明见 [0.2.12](release-0.2.12.md)。
