# 0.1.77：消息联系人复用抖音原生聊天界面

本地版本 `0.1.77 / 78`，适配抖音 `40.6.0 / 400601`。在消息页点击已配置的 AI 联系人，会打开采用宿主真实聊天布局和控件的全屏对话页。安装后完全退出并重新打开抖音，使新版模块加载。

## 界面与交互

- 根布局使用官方三个实验分支之一，保留官方顶部、消息、输入槽位；按实际输入高度排列，避开原来依赖 IM 业务协调的 275 dp 固定面板。
- 标题文字、SearchableEditText 输入栏、文本消息控件及双方气泡来自官方工厂。输入背景、页面背景和接收方气泡染色调用宿主自身的主题方法。
- 返回、头像、编辑联系人、清空、附件和发送/停止按钮由模块绑定；系统栏及键盘占用区适配全屏窗口。
- 图片、视频抽帧、文件识别、失败重试、停止请求和本地历史继续使用原有 AI 对话链路。模型设置中的测试对话继续使用原有界面。

该页面由模块本地会话驱动，没有创建抖音 IM 会话或调用官方消息发送。聊天记录与测试历史仍分开保存。版本或控件合同不匹配时提示未适配；延迟发现消息控件错误时提示并关闭页面，详细原因记录在 `DouAi.AiContact` 日志。

## 本地验证范围

原生交互 focused 测试 6 项、原始宿主 APK 合同测试 3 项通过，均无跳过。交互验证采用 Robolectric 与测试宿主工厂，覆盖可见的官方输入控件接入、本地发送、草稿保留、停止与迟到回调隔离、历史图片/文档、附件失败重试、多行输入增长和 IME 避让。实包合同测试用 dexlib2 与二进制 XML 核对反射签名和三个布局分支。

全量回归执行 148 个套件、1361 项测试。首次最终包检查因构建/测试并行读到旧 APK 而失败，其他检查通过；顺序完成 0.1.77 构建后，最终归档 APK 和原始宿主的 6 项合同检查全部通过。按每项测试的最新结果汇总为 1361 项、0 失败、0 错误、0 跳过；原始两轮报告均保留，汇总见 `artifacts/native-ai-chat-validation-summary.json`。新桥接类通过 R8 保留，宿主测试 fixtures 没有打入 APK。

静态证据和范围见 [原生界面适配记录](2026-10-18_reverse-native-ai-chat-report.md)。本地交互测试不等于真实抖音渲染验收；宿主资源/类加载、主题切换、附件选择返回和键盘行为尚未进行真机验证。本次只在本地交付。
