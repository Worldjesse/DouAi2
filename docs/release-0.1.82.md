# 0.1.82：扩展功能入口整理

版本 `0.1.82 / versionCode 83`。本版包含此前 [0.1.80](release-0.1.80.md) 的本地统计与主动 AI 分析，以及 [0.1.81](release-0.1.81.md) 的图表、关联指标与人物侧写；历史记录保留各自当时的验证结果。

“本地数据分析”和“配置备份”从设置主页移入“扩展功能”，原生与 Miuix 设置入口一致。扩展功能按以下顺序展示四项：AI 模型设置、文本转语音设置、本地数据分析、配置备份。

主页搜索支持这两个子功能的名称；输入“数据备份”也可找到“扩展功能”。打开子页后可以返回扩展列表，关闭设置时一起关闭其子页。

只调整设置导航和使用说明，沿用原有统计数据、AI 侧写、配置导入导出与签名。
