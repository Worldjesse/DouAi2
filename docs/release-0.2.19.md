# DouAi 0.2.19 本地正式版：视图查找与自定义视图

版本从 **0.2.18 / 119** 递增为 **0.2.19 / 120**，正式包名为 `io.github.yudigaga.douai`，沿用长期签名。此次为本地正式构建，不创建远端 Release。安装后完全退出并重新打开抖音。

## 纳入的改动

- 视图树支持类名、完整资源 ID、文字和内容描述的多关键词搜索，可筛选可见或可交互控件，结果展示内容摘要和当前选中项。
- 同点候选按 Z 与插入顺序切换；面板默认折叠，可拖动、展开层级导航，横屏工具条与面板分列；全量轮廓改为可选，标注避让工具条和面板。
- 完整属性可查看、选择和复制，包含尺寸、坐标、状态、布局边距、字号与颜色；密码内容不参与查询或属性复制。
- 保存规则前展示作用域、定位策略和路径，再次校验仍指向目标。自定义组件列表同步展示数量与定位说明，兼容已有 v2 规则。
