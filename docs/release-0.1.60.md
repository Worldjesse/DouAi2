版本 `0.1.60` / versionCode `61`，基于最新本地 0.1.59。沿用正式包名 `io.github.yudigaga.douai`、长期发布签名、R8 配置和抖音 40.6.0 适配，资源裁剪关闭。

- APK 关于页、源码仓库和 LSPosed 仓库增加 [免责协议](../DISCLAIMER.md)：项目仅用于学习与技术研究，用户的应用、配置、二次开发及使用行为和结果由用户自行负责，与本项目及作者无关。
- 包含 0.1.54 至 0.1.59 的本地更新：官方/第三方下载选择、自定义保存目录、通用 GET 参数与签名配置、系统/第三方文本转语音、自动语音回复和评论、离线帮助，以及语音上传和历史发送方式修复。
- 修复宿主异步语音上传返回 `false` 被误判为失败的问题，避免重复提交并保留真实回调。语音评论连续三次明确失败后复用同一正文回退文本，结果未知的提交不会直接回退。
- 保留 AI 客户端原有 4000 字输出限制；具体音频仍由合成接口、原生 SDK 和宿主服务端最终校验。
