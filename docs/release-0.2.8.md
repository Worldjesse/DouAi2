# DouAi 0.2.8：MiniMax AAC 实验选项与语音设置整理

本地候选 **0.2.8 / 109** 基于0.2.7，保留抖音40.6.0与40.8.0独立适配。评论语音按生成文件原样交给宿主，不添加本地转码、封装或改后缀转换。用户已更正：同类语音在40.6可以显示；本版不据此承诺40.8显示问题已修复。

## 本轮变化

- MiniMax生成格式可选MP3、WAV、FLAC、Ogg/Opus、G.711 μ-law WAV，以及**AAC（实验，接口可能拒绝）**。选择AAC时直接发送 `audio_setting.format=aac`；服务器拒绝会显示错误，不自动改成其他生成格式。默认仍为MP3。
- μ-law WAV请求固定8kHz，校验其真实WAV结构与G.711编码后保留同一份资源、相同文件字节；不解码成PCM文件，也不另封装。裸PCM与μ-law raw未开放为文件选项。
- 新增URL/Hex返回方式与最多四种音色混合。混音每行填写 `voice_id/weight`，单项权重1–100；启用后请求的单音色ID为空，已保存的单音色保留，清空混音即可恢复。默认返回方式为URL。
- 保留情绪、语言增强、文本归一化、采样率、声道、MP3码率、音高/音强/音色调整、声音效果、发音字典、LaTeX及AIGC水印；声音效果器仅与MP3/WAV/FLAC兼容，保存时提示冲突并提供显式重置。
- 整理语音界面：MiniMax接口信息与基本朗读参数分别合并为子页；高级设置按音频输出、语言与发音、混音与声音效果分组。配置变更会刷新打开的子页并取消旧试听/请求，已有保存值继续使用。

作品自动语音评论、评论区自动语音回复和手动 `#` 转语音均沿用原文件路径，不新增30秒截断或重试/回退变化。私聊/群聊保留既有宿主发送处理，本次没有修改其AAC路径或120秒入口限制。

## 官方依据与边界

2026-10-21核对[MiniMax同步语音HTTP API](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)：官方请求格式未列AAC/M4A。AAC是用户明确要求的实验性API值，不能称为已验证的官方能力；没有用本地转换掩盖接口结果，未使用真实账户测试其是否接受AAC。

扩展名随真实文件内容识别：ADTS AAC为 `.aac`，MPEG-4音频为 `.m4a`，Ogg/Opus为 `.ogg`，WAV为 `.wav`。修改文件名不会改变编码或容器；MiniMax若返回不同容器，会保留实际返回内容。原生抖音AAC/M4A配置仅作为[分析证据](2026-10-21_reverse-auto-voice-comment-analysis-report.md)，没有用于本地转码。

保留既有传输边界：JSON/Hex文本响应上限2MiB，URL音频下载上限20MiB；较长或无损音频使用默认URL。官方裸PCM未说明位深、字节序，本轮不猜测其封装；裸μ-law也不做本地包装。AAC与各类生成文件能否被宿主服务器接受，仍需实际发送验证。
