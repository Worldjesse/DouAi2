# DouAi 0.1.63

版本 `0.1.63` / versionCode `64`，适配抖音 40.6.0，Android 9+、libxposed API 102。沿用正式包名与发布证书。本版包含此前本地 0.1.61、0.1.62 的优化，并新增发布前要求的配置导入/导出。

## 配置备份

- 抖音内 DouAi 设置主页增加“配置备份”，通过系统文件选择器导出和导入 UTF-8 JSON，文件上限 2 MiB。
- 默认不导出接口密钥，可手动勾选包含；勾选后明文保存。无密钥备份也会省略可能含凭据的自定义请求头、参数及接口地址片段，导入后可能需要补填。回复正文、提示词等自由文本原样保留。
- 导入先展示格式、变更、移除和需补填字段数量，明确确认后才写入。默认合并，可选覆盖；切换模式重新生成预览，已有配置变化时拒绝旧预览。
- 仅在模型 ID、接口地址及第三方 App ID 等身份匹配时保留本机凭据，不将旧密钥带到其他服务或账号。
- 仅备份明确支持的功能配置；历史、运行缓存、发送账本、确认状态和重试/重置命令不进入备份。目录权限及音频文件本身不随配置文件迁移。
- 严格检查 JSON 结构、重复字段、类型、整数范围及版本。写入使用完整配置批次，失败尝试恢复原快照；导入及回滚期间阻止宿主读取临时配置，结束后再发布最终状态。Android 9/10 清空设置没有系统通知时，也会显式触发最终重载。
- 文件读写与关闭在有界后台执行，取消/关闭使未确认操作失效；已经确认的提交允许完整结束，不回写已关闭的界面。

使用方式和限制见 [配置备份帮助](help.md#配置备份导入与导出)。

## 优化与发布前修复

- 保留 0.1.61 的自动回复取消、媒体及生成截止时间、迟到结果处理、语音参数一致性和适配诊断。
- 保留 0.1.62 的 Feed 结构检查预算、下载任务进度与取消、30 分钟整体时限及回复/评论设置模块化。固定大树本地测试的结构比较次数减少约 75%，不等同于实测帧率提升。
- 独立复核发现静止大树仅有一次布局/绘制时可能无法完成后续结构检查。本版由布局事件启动一轮有界续查，保持每监视器每帧最多 256 节点；无实际变化的布局不直接触发全量目标重新发现。关闭、detach 及快照重建停止续查。
- 新增配置功能的复核修复了 token 数量字段被误脱敏、数组及裸查询凭据遗漏、整数截断、第三方账号身份错配，以及失败提交期间可能短暂启用自动化的问题。
