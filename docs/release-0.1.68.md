# 0.1.68：第三方下载分类、多选与 Miuix 弹窗

版本：`0.1.68 / 69`，基于 0.1.67。本次将第三方下载接入与官方下载相同的 Miuix 弹窗：先解析已配置的下载字段，再按图片、视频、动态视频、音频或文件选择保存内容。每个条目标明来源字段和原序号，支持单项、多选或保存整类。

## 使用

“下载相关 → 下载方式”选择“第三方下载”，保持该方式的“默认行为”关闭，再从“保存媒体”手势、手势快捷菜单或模块下载入口发起保存：

| 层级 | 显示与操作 |
| --- | --- |
| 解析 | 显示“正在解析所选下载字段”，可取消；此时会请求解析接口，但不请求、保存媒体文件或作品信息 TXT |
| 第三方下载 | 只列出解析计划中存在的“图片（N）”“视频（N）”“动态视频（N）”“音频（N）”“文件（N）” |
| 分类 | 单项保存动作标明来源字段及原序号；多项提供“选择…保存”和“保存全部…” |
| 多选 | 只列出所属类型，使用“来源字段 · 第 N 项”标明各条来源；勾选后点击“保存” |

分类页和多选页都有“返回”和“取消”。返回回到上一层，取消结束本次选择；空选点击保存会提示选择媒体。第三方响应没有宿主当前图位置，因此不提供虚构的“保存当前项”。

例如 `data.images` 中重复地址去重后剩下原第 1、3、4 项，选择框仍显示这些来源序号。只保存原第 1、4 项时，保留原计划中对应的文件名与全局序号，不将它们重新编号为第 1、2 项。作品信息 TXT 随选定的作品包保存，不作为可选媒体加入类型列表。

只使用“下载字段”中已配置且本次响应确实解析出的内容。菜单不会自动加入其他字段中的媒体，也不会因为缺少某一类型而读取宿主来源。第三方命名字段、共享保存位置和原有作品信息整理方式继续生效。

## 默认行为与分类边界

第三方下载新增独立的“默认行为”开关，默认关闭。开启后，解析成功即直接保存所有已配置下载字段中的媒体，跳过分类和多选。它与官方下载的同名开关分别保存；切换下载方式不会将一个开关的状态套用到另一种方式。

动态视频需要计划中的视频 MIME 类型和来源字段的明确含义共同确认，例如字段包含独立的 `motion`、`dynamic` 或 `live_video` 标记，兼容 `dynamicVideo`、`liveVideo` 等驼峰写法。普通视频不会因为 URL 文本中出现这些词而变成动态视频，图片字段中的同名标记也不会将图片变成动态视频。

第三方响应中的图片和视频按各自类型保存，不按顺序或数量任意配成实况照片。官方下载的实况识别与原生编码流程继续沿用 [0.1.67](release-0.1.67.md)、[0.1.66](release-0.1.66.md) 和 [0.1.65](release-0.1.65.md) 的说明。

## UI 对齐

解析提示、媒体类型、分类动作和多选页均使用现有 `MiuixDialogBuilder`，复用设置页的字体、圆角、配色、按钮、勾选控件及系统深浅色适配。多项列表可滚动，底部保留取消、返回和保存按钮。

新增本地 Compose 渲染测试覆盖 296 dp 小屏的类型与来源字段列表、系统深色但宿主强制浅色的界面，以及 640×360 横屏动态视频多选。测试通过真实 Compose 控件点击、勾选、滚动和返回；设置 `DOUAI_CHAT_SCREENSHOTS` 可导出检查用 PNG。本地渲染结果只用于界面检查，不代表真机截图。

## 保存与生命周期

- [ThirdPartyDownload](../app/src/main/java/com/douai/module/feature/ThirdPartyDownload.java) 将解析与确认后的媒体保存分成两个阶段。进入分类、勾选或返回都不提交媒体保存任务；解析请求本身仍可能消耗第三方接口额度。
- 解析和选择阶段归当前页面所有。取消、系统关闭、页面暂停或销毁、设置变化会关闭尚未确认的会话并取消解析。手势入口切换作品时也会清理会话；各入口在打开、解析完成和提交选择时复核当前作品，丢弃失效后的迟到结果。旧窗口回调不能提交新的保存请求。
- 用户确认并被下载队列接受后，保存任务独立运行。之后关闭界面或切换作品不会取消已接受的保存，可到“下载相关 → 下载任务”查看进度或取消。
- [ThirdPartyDownloadDialog](../app/src/main/java/com/douai/module/feature/ThirdPartyDownloadDialog.java) 关闭自身后再将选定计划交给保存阶段。用户取消与系统关闭只通知一次，分类窗口替换和程序清理不会误触发用户取消。
- [ThirdPartyDownloadPlan](../app/src/main/java/com/douai/module/feature/ThirdPartyDownloadPlan.java) 生成不可变子集，保留原文件名、来源字段、来源位置、作品包名及元数据，按原计划顺序保存所选媒体和信息 TXT。
- 已选择第三方下载时，解析失败、取消、空选、失效或下载失败均不会回退到官方下载，也不会额外保存未勾选媒体。开启第三方“默认行为”时仍只执行第三方流程。
