# 0.1.78：修正聊天页外观与模型头像入口

本地版本 `0.1.78 / 79`，适配抖音 `40.6.0 / 400601`。本轮根据用户提供的现状与官方单聊截图，继续修正 0.1.77 中仅复用部分控件造成的外观差异，同时调整模型配置页的头像和联系人开关。

## 用户可见变化

- 聊天标题栏使用原生返回和更多图标，修改联系人、清空记录收进更多菜单。
- 每条消息显示原生圆头像；AI 使用配置头像，自己一侧读取当前抖音账号的头像模型，交给宿主正常图像加载器。
- 发送气泡使用官方白字，接收方使用官方主题字色；气泡沿用官方 12 dp 资源圆角，内容间距取原生背景工厂，宽度采用宿主预算并限制在本地可用空间内。
- 消息上方复用原生大头像和昵称资料区域，底部复用原生快捷卡片、工具/语音/表情/加号图标和输入栏原有的发送控件。没有创建官方 IM 会话或套用陌生人发送限制。
- 模型配置页的头像放到“模型配置”标题下方居中。点击头像打开“选择图片 / 恢复默认”菜单，页面不再显示独立选择/恢复按钮；“加入抖音消息界面”开关位于表单底部。

## 使用

在 AI 模型编辑页点击顶部头像设置图片，填写联系人名字，在底部开启“加入抖音消息界面”并保存。返回消息页打开联系人。右上角更多菜单用于修改联系人或清空聊天记录；加号选择图片、视频或文件。

表情和快捷卡片仅填写草稿，点击发送才提交 AI 请求。语音按钮通过设备安装的系统语音识别服务填入文字，没有可用服务时提示；不调用抖音录音上传或 IM 发送。图片/文件识别、停止、失败重试、上下文和本地历史继续使用既有链路。
