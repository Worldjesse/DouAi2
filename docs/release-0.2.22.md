# DouAi 0.2.22 正式版：评论回复浮窗、Miuix 查找与运行时优化

版本 **0.2.22 / 123**，包名 `io.github.yudigaga.douai`，沿用长期签名。GitHub 标签为 [`v0.2.22`](https://github.com/yudigaga/DouAi/releases/tag/v0.2.22)，LSPosed 标签为 [`123-0.2.22`](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.douai/releases/tag/123-0.2.22)，两处发布同一份已验证 APK。

本地专项清单保留验收时的 `verified-targeted-release`、`fullSuiteRun=false`、`published=false` 快照；远端发布状态与资产摘要单独记录，不改写原封存证据。

## 相对 0.2.18 的累计更新

- 视图查找支持树搜索、筛选、重叠控件切换、完整属性复制和规则路径预览；工具条、选择面板与列表统一使用 Miuix，跟随系统明暗主题。
- 修复自定义视图删除确认框缺少导航环境导致的闪退，为嵌入宿主的查找界面隔离导航与生命周期。
- 减少空轮询、重复反射和隐藏树巡检；优化名单调度、日志写入、媒体内存预算、统计事务和启动缓存。性能数据来自本地夹具，设备 CPU、耗电和帧率仍待测量。
- 评论回复从排队及素材、模型、语音准备阶段登记共享浮窗，完善取消、异常和迟到更新清理；保留原发送确认、语音质量、提示词与重试/回退语义。

0.2.19 至 0.2.21 的独立构建与测试记录保留在各自版本文档中，不累计成 0.2.22 的测试次数。继续支持抖音 40.6.0 / 400601 和 40.8.0 / 400801，40.8 仅加载内部构建 40809900。

## 修复与依据

评论区自动回复此前在素材、模型及语音全部准备好后才登记浮窗；0.2.18 旧源码中已经存在此缺口。现在从等待阶段登记，随素材、模型和语音更新同一条展示状态，再进入原预览及原生提交；补足取消与异常清理，保留原发送、预览时间、语音和重试策略。简单日志新增脱敏展示诊断，按状态变化记录。

已检查用户当前及旧详细日志，并以本地 Robolectric 集成回归复现准备期缺窗。现有日志没有把用户所说的每次“正常发出但全程无窗”与具体窗口状态绑定；本次修复不能单独证明所有真机偶发情况均已消失。证据与剩余边界见[历史日志与修复依据](2026-10-25_comment-reply-overlay-report.md)。
