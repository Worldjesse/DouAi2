# DouAi 0.2.21 本地正式版：运行时开销优化

版本 **0.2.21 / 122**，包名 `io.github.yudigaga.douai`，沿用长期签名和原 R8 保留规则。本版已完成严格本地验收，状态 `verified-local`、`fullSuiteRun=true`、`published=false`；没有发布远端。

## 变更与性能证据

减少关闭功能后的定时扫描、重复选中解析、反射查找和隐藏节点巡检；拆分名单与续火花调度，后台按需加载名单；日志小批写入、媒体流式处理和共享预算、统计事务合并，以及启动清单和报告复用。保留发送前持久化、未知结果防重、账号隔离和语音质量、提示词及重试/回退语义。原 0.2.20 的查找器改动一并保留。

夹具中稳定大树 300 帧结构检查由 76,800 次降至 19,500 次；64 条排队统计写入由 64 次事务合为 4 次，计数不丢。详细实施、R8 同源对比、完整性与测量边界见[性能实施记录](2026-10-25_performance-implementation-report.md)。这些数字不代表真机 CPU 或电耗降幅。
