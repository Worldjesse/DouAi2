# DouAi 0.1.58

版本 `0.1.58` / versionCode `59`，基于 `0.1.57`。沿用正式包名、发布签名、R8 配置和抖音 40.6.0 适配规则。本版仅在本地构建，未上传 GitHub 或 LSPosed。

## 问题与证据

用户反馈自动语音评论频繁失败，但文本转语音设置中的试听可用。提供的 LSPosed 日志包含 16 次生成阶段 `IllegalArgumentException`、2 次原生发布失败和 1 次成功回执。旧日志缺少异常原因、正文长度、音频时长与具体阶段，无法确认每次失败的根因，成功回执也不能独立证明当次使用了语音模式。

代码中确有评论正文 1000 字符、评论音频 30 秒、共享合成 120 秒限制，第三方合成还误用了 Android 系统 TTS 文本长度上限。自动评论额外调用私聊 AAC 转码，设置试听和手动评论没有这一步；转码可能因设备解码格式或缓冲区要求失败。宿主评论发布和上传流程使用音频源路径，已核对的 Java/smali 路径未强制上述时长或 AAC 格式。抖音录音界面的默认 30 秒倒计时不等同于已核实的服务端发布上限。

## 更新

- 自动语音评论将已验证的合成源文件交给评论上传流程，与手动评论路径一致，去掉私聊 AAC 转码。
- 自动及手动 `#` 合成评论取消模块 30 秒时长拦截；自动语音评论免于文字评论的 1000 字符检查，仍只发送语音，失败不会回退文字。
- 第三方合成不再套用系统 TTS 文本上限。共享合成移除 120 秒拦截，试听和手动私聊 `#` 同样沿用这一共享行为；系统来源仍受 Android 语音引擎要求约束。
- 按用户补充要求，AI 客户端原来的 4000 字符输出限制保持不变，输入、响应大小与结构检查也保持原有规则。普通文字评论继续使用原有校验。
- 自动私聊/群聊语音回复独立的 120 秒限制，以及录音文件替换评论的 30 秒限制保持原有行为。音频有效性、文件大小、网络超时、取消、去重和宿主权限校验仍生效。
- 增加自动评论的失败阶段、固定原因码、字符数、音频真实时长与文件大小诊断。原生回调仅记录响应类型及可获取的数字状态/错误码，不记录正文、密钥或媒体地址。
- 保留语音源文件所有权，成功或终止失败时清理，发布重试复用已准备文件；结果未知的提交继续保留至回调或原有清理期限。重复和迟到的合成回调不会删除已交给发送方的文件。
- 应用内帮助和 [完整帮助](help.md) 同步更新。
